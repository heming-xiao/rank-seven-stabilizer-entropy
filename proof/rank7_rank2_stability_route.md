# 秩二 Pauli 稳定性与低尾秩七谱

2026-11-17。以下证明任意量子比特二分割上的一个秩七谱类。将最大的两个相等 Schmidt 概率共同缩放为 1。若

    t₀=t₁=1,     1/32 ≥ t₂ ≥ t₃ ≥ t₄ ≥ t₅ ≥ t₆ > 0,

则排序计算基代表全局最大化稳定子纯度。后五个概率可相异，且彼此的比值不受限制。证明通过秩二 Pauli 四次矩对稳定子编码的定量逼近，以及原文缺陷项对五点超额的支付。[两级谱的原归约](rank7_two_level_defect_route.md) · [Sierant，arXiv:2609.13106v2](https://arxiv.org/html/2609.13106v2)

## 秩二四次矩与稳定子编码

令 \(P\) 为二平面 \(X\) 上的投影，令 \(a_W=\operatorname{Tr}(PW)/2\)，其中 \(W\) 遍历 Hermitian Pauli。设 \(m=d/2\) 与

    δ = [8d−F_P(P)]/(8d) = m^(−1) Σ_W a_W²(1−a_W²).

Parseval 给 \(\sum_W a_W^2=m\)，且 \(|a_W|\le1\)，故 \(F_{\mathrm P}(P)\le 8d\)。若 \(W,W'\) 反对易，则对态 \(P/2\) 应用 \((a_W W+a_{W'}W')^2=(a_W^2+a_{W'}^2)I\)，得到 \(a_W^2+a_{W'}^2\le1\)。因此高值标签集 \(H_{\mathrm{hi}}=\{W:a_W^2>1/2\}\) 两两对易，并且

    Σ_(W∈H_hi) a_W² ≥ m(1−2δ).

这是因为低值部分有 \(a_W^2(1-a_W^2)\ge a_W^2/2\)。先将这些模相位标签扩张到任一最大交换 Pauli 群。其退相干把 \(P\) 送到对角元 \(g_i\in[0,1]\)、\(\sum_i g_i=2\) 的对角矩阵 \(P_{\rm diag}\)。群外的 Pauli 平方范数至多 \(4\delta\)，即 \(\|P-P_{\rm diag}\|_{\mathrm{HS}}^2\le4\delta\)。取最大的两个对角元对应的投影 \(Q\)。这两条稳定子线的直和是一个秩二稳定子编码，因为它们的两个字符在一个余维一的 Pauli 子群上取相同的值。由 \(g_i\in[0,1]\) 与 \(\sum_i g_i=2\)，有 \(\sum_i g_i^2\le g_{(1)}+g_{(2)}=\operatorname{Tr}(PQ)\)。于是

    ε := 1−Tr(PQ)/2 ≤ 2δ.

这里的对角元不等式，也可把 \(\sum_i g_i u_i\) 对 \(0\le u_i\le1,\ \sum_i u_i=2\) 最大化后取 \(u=g\) 得出。特别地，四次矩取等强制 \(P=Q\)。反过来，秩二稳定子编码在 \(d/2\) 个标签上有 \(|a_W|=1\)，其余为零，故取等。

当 \(\delta\le1/14\)，还可以令 \(Q\) 来自**高值标签本身生成**的群 \(H\)。高值质量使 \(|H|>m/2\)，而 \(H\) 交换，所以 \(|H|\in\{m,d\}\)。设 \(|H|=d\)。在其一维共同本征线上，态 \(P/2\) 的概率 \(p_j\le1/2\)，且字符 Parseval 给 \(\sum_j p_j^2\ge(1-2\delta)/2\ge3/7\)。令 \(p_{(1)}\ge p_{(2)}\) 为前两项，则

    p_(1) ≥ 3/7,
    p_(2) ≥ [Σ_j p_j²−p_(1)²]/[1−p_(1)]
           ≥ (3/7−1/4)/(1−3/7) = 5/16.

对任一高值标签，少数符号的总概率为 \((1-|a_W|)/2<(1-1/\sqrt2)/2\)。故这两个概率对应的字符在每个高值标签上的符号都相同，不能由它们生成整个 \(H\)。这与两个不同本征字符相矛盾。因此 \(|H|=m\)。此时字符对应秩二联合本征空间，概率 \(p_\lambda\) 有 \(\sum_\lambda p_\lambda^2\ge1-2\delta\)。取最大概率处的编码投影 \(Q\)，便有 \(\varepsilon\le2\delta\)，且群中每个 \(W\) 都在 \(Q\) 上作用为标量符号。

## 五点量对编码距离的二阶控制

取任意五维 \(Y\subseteq X^\perp\)。在所有二形式上定义 \(M_Y\) 的二次型为 \(q^{-1}\sum_{i<j}\|\Pi_{\mathrm F}(\alpha\wedge y_i\wedge y_j)\|^2\)。Theorem 17 的单洞满射给，对任意三形式 \(\eta\)，\(\sum_j\|\Pi_{\mathrm F}(\eta\wedge e_j)\|^2=q\|\eta\|^2\)，其中 \(e_j\) 遍历完整标准正交基。以 \(\eta=\alpha\wedge y_i\) 应用此式，并在 \(i,j\in Y\) 上求和，得到

    0 ⪯ M_Y ⪯ (5/2) I.

令 \(L=2I-M_Y\)。已有的稳定子锚点算子界给 \(L\) 在 \(s\wedge E\) 上的压缩半正定，对每个单位稳定子 \(s\) 成立，即使 \(s\) 不正交于 \(Y\)。理由是把 \(Y\) 的五维体积元按该二平面的占据数 \(0,1,2\) 分块，并应用已证的 \(A_5,A_4,A_3\) 锚点界。[稳定子锚点算子界](reviews/rank7_two_link_independent_review.md) · [允许非正交体积元的分块](rank7_joint_gram_astra.md)

令 \(s_0,s_1\) 是编码 \(Q\) 的一组稳定子标准正交基，\(\alpha_0=s_0\wedge s_1\)。把 \(X\) 的单位二楔按 \(Q\) 占据分解为

    α=cα₀+η₀+η₁+ζ,      η_i∈s_i∧Q⊥,      ζ∈Λ²Q⊥.

从两个主角的正弦平方之和 \(2\varepsilon\) 得 \(\|\eta_0\|^2+\|\eta_1\|^2\le2\varepsilon\)、\(\|\zeta\|\le\varepsilon\)。对每个 \(i\)，\(\alpha_0,\eta_i\) 共用稳定子锚点 \(s_i\)，故半正定压缩的 Cauchy–Schwarz 可控交叉项。记 \(b_i^2=\langle\eta_i,L\eta_i\rangle\ge0\)、\(a=|c|\sqrt{\langle\alpha_0,L\alpha_0\rangle}\)。保留这两组锚点交叉项及三项对角量，所得下界是

    a²+b₀²+b₁²−2a(b₀+b₁) ≥ −2b₀b₁ ≥ −4||η₀|| ||η₁||.

另外 \(L-\tfrac34I\) 的范数至多 \(5/4\)，故任意两正交向量的 \(L\) 交叉量可用此常数估计。加上 \(\eta_0,\eta_1\) 之间的交叉项，前面三项的下界为 \(-\frac{13}{2}\|\eta_0\|\|\eta_1\|\ge-\frac{13}{2}\varepsilon\)。与 \(\zeta\) 的交叉量至多 \(\frac52\varepsilon\)，其自身下界为 \(-\frac12\varepsilon^2\)。由此得到所需的线性稳定性

    (V−2)_+ ≤ 9ε+ε²/2 ≤ 10ε ≤ 20δ.                 (1)

这里 \(V\) 正是单位可分解 \(\alpha\) 在 \(M_Y\) 上的期望。更粗的普适界 \((V-2)_+\le1/2\) 也由 \(M_Y\preceq(5/2)I\) 得到。

## 五个独立尾概率只需要同一个五点超额

在排序正支撑上记 \(a_i'=1/t_i\)，并写 \(a'_i=\sum_{j\le i}b_j\)。此处 \(t_0=t_1=1\)，所以 \(b_1=0\)。任意尺寸的精确对偶已逐项证明 84 个三次单项式中的 75 个系数由排序参考最大化。剩下九个中，只有 \(222,223,224,233\) 不含 \(b_1\)。这四项只依赖 \(R=\{2,3,4,5,6\}\) 里的补三元组。用 \(R\) 内三元组的补边作图边，则总权为 \(V\)，每个顶点的加权度 \(d_i\le1\)，这是去掉该顶点后的四点容量行。[基础精确系数证书](rank7_ambient_reduction.md)

| 系数 | 在补边图中的目标 | 排序值 | 目标超额上界 |
|---|---|---|---|
| \(222\) | \(V\) | 2 | \((V-2)_+\) |
| \(223\) | \(2V+d_2\) | 5 | \(2(V-2)_+\) |
| \(224\) | \(V+d_2+d_3\) | 4 | \((V-2)_+\) |
| \(233\) | \(V+2d_2\) | 4 | \((V-2)_+\) |

\(223,224\) 分别数三元组中至少为 3、4 的标签，\(233\) 选两枚至少为 3 的标签。排序三元组 \(236,456\) 的补边给 \(d_2=d_3=1\)。所以去掉所有已证非正的系数差后，恢复共同因子 \(q\prod_i t_i\) 得

    c_F(N²)−c_F(M²) ≤ q W_spec (V−2)_+,
    W_spec = (Π_i t_i) b₂[(b₂+b₃)²+b₂b₄]
           = t₅t₆ [(1−t₂)(1−t₃)² t₄/t₃ +(1−t₂)²(t₃−t₄)/t₂]
           ≤ t₅t₆ ≤ r²,      r=t₂.

倒数差中的等号来自直接代入。末个系数界用 \(t_4/t_3+(t_3-t_4)/t_2\le1\)。因此 Proposition 2 与 Theorem 7 给

    G_μ(V_orbit)−G_μ(I) ≤ 168r²(V−2)_+ − D(N).      (2)

## Pauli 缺陷在 r≤1/32 支付全部超额

写 \(C=N^2=P+K\)，其中 \(PK=0\)，\(K\) 的五个正特征值为 \(t_2,\ldots,t_6\)。由 Eq. (175)，\(\mathcal D(N)\ge\Delta_d(C)/d\)。Theorem 14 的非对易平方和及 Pauli Parseval 给

    Δ_d(C)/d ≥ (4/d²) Σ_(unordered W,W' anti) Tr(CW)² Tr(CW')²
             = (1/(2d)) Σ_W Tr(CW)² ||[C,W]||_HS².              (3)

第二式展开交换子，再用 \(W W' W=\pm W'\) 即得。\(P\) 对应 \(C\) 的本征值 1，在其他本征空间的谱至少相差 \(1-r\)。因此逐个交叉矩阵元有 \(\|[C,W]\|_{\mathrm{HS}}\ge(1-r)\|[P,W]\|_{\mathrm{HS}}\)。[Sierant，Theorem 14、Eq. (175)](https://arxiv.org/html/2609.13106v2)

**接近编码时。** 设 \(\delta\le1/14\)，取高值生成群的编码 \(Q\)。对 \(W\in H\)，其在 \(Q\) 上为标量符号，所以 \(|a_W|\ge1-2\varepsilon\ge5/7\)。因 \(|\operatorname{Tr}(KW)|\le5r\)，有 \(|\operatorname{Tr}(CW)|\ge10/7-5r>5/4\)。按整体符号使 \(PWP\) 的迹为 \(2a\)，其中 \(a=|a_W|\ge5/7\)。两个压缩特征值在 \([-1,1]\)，固定和为 \(2a\)，所以它们的平方和至多 \(1+(2a-1)^2\)。于是

    ||[P,W]||_HS² = 2[2−Tr((PWP)²)]
                  ≥ 8a(1−a) ≥ (10/3)(1−a²).

编码概率的最大项为 \(1-\varepsilon\)。字符 Parseval 及其余概率的总和 \(\varepsilon\) 给 \(\sum_{W\in H}(1-a_W^2)\ge 2m\varepsilon(1-\varepsilon)\ge(6/7)d\varepsilon\)。只保留 (3) 的群内项，因此

    Δ_d(C)/d ≥ (125/56)(1−r)² ε ≥ 2ε,
    168r²(V−2)_+ ≤ (1680/1024)ε < 2ε    (ε>0).

第一式对 \(r\le1/32\) 成立。若 \(\varepsilon=0\)，所需超额也为零。

**远离编码时。** 设 \(\delta\ge1/14\)。记 \(p_W=\operatorname{Tr}(PW)\)、\(k_W=\operatorname{Tr}(KW)\)，以 \(\langle f\rangle=d^{-1}\sum_W f_W\) 表示缩放和。Parseval 给

    ⟨p k⟩=0,   ⟨p²(4−p²)⟩=8δ,   ⟨k²⟩=s₂=Tr(K²)≤5r².

因此一阶项满足

    |⟨p³ k⟩| = |⟨p(p²−4)k⟩| ≤ sqrt(32δ s₂) ≤ sqrt(160δ)r.

在 \(F_{\mathrm P}(C)/d=\langle(p+k)^4\rangle\) 中，其余三项分别用 \(\langle p^2 k^2\rangle\le4s_2\)、\(|\langle p k^3\rangle|\le10r s_2\) 和 \(\langle k^4\rangle\le25r^2 s_2\)。其中三次项可先用 Cauchy–Schwarz，再用 \(|p|\le2\)、\(|k|\le5r\)。在 \(\Delta_d(C)/d\) 的谱项里，\(3(\operatorname{Tr}C^2)^2-2\operatorname{Tr}C^4\ge 8+12s_2\)，因为 \(\operatorname{Tr}K^4\le s_2^2\)。另有 \(c_{\mathrm F}(C)\ge0\)。合并得

    Δ_d(C)/d ≥ 8δ−16√10 r√δ−60r²−200r³−125r⁴.

由于 \(r/\sqrt\delta\le\sqrt{14}/32\) 且 \(\sqrt{140}<237/20\)，前两项之和至少为 \(83/560\)。其余三项的绝对总和小于 \(13/200\)。因此 \(\Delta_d(C)/d>233/2800>84/1024\)，而普适五点上界给 \(168r^2(V-2)_+\le84/1024\)。

两种情形都使 (2) 非正，得到任意平衡维数的单酉比较。Lemma 1 将该结论转为两侧任意局部酉的比较。对不平衡切割，补齐较小一侧的纯 stabilizer 辅助位保持排序代表纯度，且原局部酉可作为扩维问题的可行酉，给出同一结论。统一缩放概率的正因子不改变比较。一般尾谱不在上述范围时，缺陷支付仍需要其他估计。[Sierant，Lemma 1、Sec. III.1](https://arxiv.org/html/2609.13106v2)
