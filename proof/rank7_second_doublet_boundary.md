# 允许第二、第三 Schmidt 概率并合的秩七邻域

2026-11-17。令排序正概率共同归一到 \(t_0=1\)。对每个 \(g>0\)，存在显式 \(r_{\rm mid}(g)>0\)，使得

    t₀−t₁≥g,    t₂−t₃≥g,    0<t₆≤r_mid(g)

保证任意量子比特二分割上的排序计算基最优。此处 \(t_1-t_2\) 可以为零或任意小。故一切最高概率简单、下一概率恰为二重且与其余值隔开的秩至多六边界谱，均有一个**允许该重根任意分裂**的相对秩七邻域。以下用正向余项在这两根线上的对称组合，并以两条线不保真度的几何平均控制非对称余项。[不加谱矩条件的提取](reviews/rank7_moment_free_boundary_neighborhood_review.md) · [正向系数](rank7_forward_coefficients_independent.md)

## 不对称的两锚点五点界

设实际固定二腿是 \(x_0,x_1\)，参考 \(s_0,s_1\) 来自同一个稳定子基。记 \(e_i=1-|\langle s_i,x_i\rangle|^2\)。对任意与实际二腿正交的五维空间 \(Y\)，有

    (L₀₁−2)_+ ≤ 29 √(e₀e₁).                              (1)

核算沿用 \(M_Y\) 在全部二形式上的界 \(0\preceq M_Y\preceq(5/2)I\)。令 \(Z=2I-M_Y\)。固定一个稳定子 \(s\) 时，\(Z\) 在 \(s\wedge E\) 上的压缩半正定，即使 \(Y\) 不与 \(s\) 正交。原因是稳定子锚点的任意五形式算子界按锚点二平面的占据数分块后仍成立。[锚点压缩](rank7_joint_gram_astra.md)

按参考平面 \(Q=\operatorname{span}(s_0,s_1)\)，把 \(\alpha=x_0\wedge x_1\) 正交分解为 \(c(s_0\wedge s_1)+\eta_0+\eta_1+\zeta\)，其中 \(\eta_i\in s_i\wedge Q^\perp\)、\(\zeta\in\Lambda^2 Q^\perp\)。分别与 \(s_0\wedge s_1\) 共用相同锚点的 \(\eta_i\) 可以用半正定 Cauchy–Schwarz 控制交叉项。对这三项的对角及两个共用锚点的交叉项配方，负贡献至多 \(4\|\eta_0\|\|\eta_1\|\)。余下相互正交的项之间，\(\|Z-\frac34 I\|\le5/4\) 给交叉项上界，而 \(\zeta\) 的对角项至少为 \(-\|\zeta\|^2/2\)。所以

    (L₀₁−2)_+
       ≤ (13/2)||η₀||||η₁|| +(5/2)||ζ|| +||ζ||²/2.

分别展开 \(x_0=a s_0+b s_1+u\)、\(x_1=c' s_0+d s_1+v\)，其中 \(u,v\perp Q\)。因 \(|b|,\|u\|\le\sqrt{e_0}\)、\(|c'|,\|v\|\le\sqrt{e_1}\)，有 \(\|\eta_0\|=\|av-c'u\|\le2\sqrt{e_1}\)、\(\|\eta_1\|=\|bv-du\|\le2\sqrt{e_0}\)，且 \(\|\zeta\|=\|u\wedge v\|\le\sqrt{e_0e_1}\)。代入即为 (1)。

## 将整个第二、第三本征平面舍入

设 \(\eta=\Delta_d(C)/d\)，\(C=N^2\)。使用高值提取、稀少字符核、全局逻辑 Pauli 截断的 \(\eta_{\rm set},D_0,L\) 和 \(s=g/(8L)\)、\(D_2=D_0+L/(4s^2)\)。在

    η ≤ η_* := min(η_set, s⁴/L², g²/(64D₀), g²/(16D₂))

时，逻辑截断 \(F_{\rm hi}\) 与 \(C\) 的算子范数距离至多 \(g/4\)，且 \(F_{\rm hi}\) 在所得交换群 \(G\) 的字符块上标量。[全局逻辑截断](rank7_isolated_doublet_boundary.md)

在 \(t_0,t_1\) 的中点以上，\(F_{\rm hi}\) 恰有一个本征值。因此字符块维数必须为一，\(G\) 最大交换。令 \(D=\mathcal E_G C\)，则 \(\|C-D\|_{\rm HS}^2\le D_2\eta\)、\(\|C-D\|_{\rm op}\le g/4\)。\(D\) 的最大本征线 \(s_0\) 简单。其第二与第三大本征值对应整个秩二谱投影 \(Q_{12}\)，由同一个稳定子基的两根向量 \(s_1,s_2\) 张成。即使这两个本征值相等，也可这样取基。

对实际最大谱线 \(P_0\) 和实际第二、第三谱平面 \(P_{12}\)，逐项比较 \(C\) 和 \(D\) 的异簇本征向量。由于异簇谱差至少 \(g/2\)，由 \((t_i-\lambda_j)\langle w_j,x_i\rangle=\langle w_j,(C-D)x_i\rangle\) 平方求和得

    e₀ = 1−|⟨s₀,x₀⟩|² ≤ 4D₂η/g²,
    Tr[P₁₂(I−Q₁₂)] ≤ 4D₂η/g².

特别地 \(e_0\le1/4\)。从 \(P_{12}s_1\) 归一化取实际平面的一根向量 \(x_1'\)，补成正交基 \(x_1',x_2'\)。它对稳定子线 \(s_1\) 的平方不保真度至多 \(\operatorname{Tr}[P_{12}(I-Q_{12})]\)。因此 \(x_0,x_1'\) 对共同稳定子基两线的总失配至多 \(8D_2\eta/g^2\)。

## 对称项沿平面舍入，余项沿各线舍入

正向权重满足

    γ₀₁(L₀₁−2)+γ₀₂(L₀₂−2)
      = γ₀₂(L₀₁+L₀₂−4) + β(L₀₁−2),
    β = γ₀₁−γ₀₂ = t₆² b₁ (t₀−t₃),      b₁=t₁−t₂.

这里 \(L_{01}+L_{02}\) 在旋转 \(x_1,x_2\) 的共同张成平面时保持。具体说，在前七正支撑的四楔投影和里，固定含 \(x_0\)，含平面 \(P_{12}\) 一腿或两腿的项分别取权 1 或 2。这是 \(x_0\wedge P_{12}\wedge\Lambda^2 Y_4\) 与 \(x_0\wedge\Lambda^2 P_{12}\wedge Y_4\) 上的两项迹，其中 \(Y_4\) 为其余四维空间，因此各自与平面基无关。

将对称项在 \(x_1',x_2'\) 的基下计算。两个配对的联合补偿取比值 1，得

    L₀₁+L₀₂−4 ≤ 126500 (8D₂η/g²).

对非对称项，如果 \(b_1=0\) 则 \(\beta=0\)。若 \(b_1>0\)，实际第二本征线 \(x_1\) 的谱隙至少 \(\min(g,b_1)\ge g b_1\)，因为 \(g,b_1\le1\)。逐矩阵元比较 Pauli 交换子，再对 \(G\) 平均，给

    ||P_x₁−E_G P_x₁||_HS² ≤ D₂η/(g² b₁²).

所以对共同稳定子基中最大概率对应的线，\(x_1\) 的不保真度不超过右端。若该线不是 \(s_0\)，直接以其为参考。若它就是 \(s_0\)，则最大概率也至多 \(e_0\le1/4\)，因实际 \(x_0,x_1\) 正交。此时右端至少 \(3/4\)，任取一条不同于 \(s_0\) 的稳定子线就使失配至多右端的两倍。因此总可选一条 \(s_1'\ne s_0\) 使 \(e_1\le2D_2\eta/(g^2 b_1^2)\)。用 (1) 得

    β(L₀₁−2) ≤ 58√2 t₆² D₂ η/g² ≤ 83 t₆² D₂ η/g² .

由 \(\gamma_{02}\le t_6\)、\(t_6^2\le t_6\)，两部分加起来至多 \(1012083\,t_6 D_2\eta/g^2\)。此估计在 \(b_1\downarrow0\) 时常数保持。使用半差的平方比例会留下 \(1/b_1\)，而 (1) 只需两条失配的几何平均。[两配对补偿](reviews/rank7_single_anchor_compensation_independent_review.md)

## 纯度比较

取

    r_mid(g) = min(η_*/336, g²/[168·1012083 D₂]).

正向证书和 Proposition 2、Theorem 7 将纯度差界为该加权组合的 \(168\) 倍再减 \(\eta\)。若 \(\eta\le\eta_*\)，上述加权界和 \(t_6\le r_{\rm mid}(g)\) 已支付。若 \(\eta>\eta_*\)，用 \((L_{0i}-2)_+\le1/2\) 与 \(\gamma_{02}\le\gamma_{01}\le2t_6\)，其 \(168\) 倍至多 \(336 t_6\le\eta_*\)。两种情形均得到计算基最优性。Lemma 1 转回任意复局部酉，较小侧填充纯稳定子位处理不平衡切割。[Sierant，Lemma 1、Proposition 2、Theorem 7](https://arxiv.org/html/2609.13106v2)
