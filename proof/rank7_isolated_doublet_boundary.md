# 孤立最高双峰的秩七边界邻域

2026-11-17。将排序 Schmidt 概率共同归一到 \(t_0=t_1=1\)。对于每个 \(g>0\)，存在显式的 \(r_{\rm eq}(g)>0\)，使得

    1−t₂≥g,     0<t₆≤r_eq(g)

足以保证任意量子比特二分割上的排序计算基全局最优性。中间四项 \(t_2,\ldots,t_5\) 无须弱或有重根。特别地，任意秩二至六的等顶边界谱，只要最高值恰有二重，就有保持这一顶重根的相对秩七邻域。此处用整个最高双峰的谱隙，不需要在精确重根内选择被舍入的两条有序线。[高值标签提取的独立核验](reviews/rank7_moment_free_boundary_neighborhood_review.md)

## 全部字符块的逻辑 Pauli 质量

令 \(C=N^2\)，\(\eta=\Delta_d(C)/d\)。沿用无谱矩条件的高值提取和稀少字符核构造中的固定常数 \(\eta_{\rm set},D_0,L\)。在 \(\eta\le\eta_{\rm set}\) 下得到交换群 \(H'\)，使各共同字符块 \(Q_\lambda\) 的维数 \(l=d/|H'|\le L\)，以及

    ||C−E_(H') C||_HS² ≤ D₀ η.

对每个逻辑标签 \(v\in (H')^\perp/H'\)，取 Hermitian Pauli 代表 \(U_v\)，令

    a_v² = |H'|^(−1) Σ_(W∈U_v H') Tr(CW)²
         = Σ_λ u_(λ,v)²,     u_(λ,v)=Tr(Q_λ C Q_λ U_v).

第二式是 \(H'\) 上的字符 Parseval。这次对所有共同字符块求平方和。不同逻辑反对易标签的两个完整 coset 之间全部反对易，因此原文缺陷给

    η ≥ (4/l²) Σ_(unordered logical v,w anti) a_v² a_w².    (1)

取 \(s=g/(8L)\)，设 \(\eta\le s^4/L^2\)。由 (1)，满足 \(a_v>s\) 的逻辑标签两两对易。令 \(G\) 为这些标签所生成逻辑群在 \((H')^\perp\) 中的逆像，它是包含 \(H'\) 的一个交换群，暂不要求最大。任一 \(W\in (H')^\perp\setminus G^\perp\) 与某个高值生成元反对易，故与该元的整个 coset 反对易，对方迹平方和大于 \(|H'|s^2\)。各计入的对在 \(G\) 里恰有一个端点，按 \(W\) 求和无重复。联合此前对 \(W\notin(H')^\perp\) 的控制，得

    ||C−E_G C||_HS² ≤ D₂ η,    D₂=D₀+L/(4s²).              (2)

这也覆盖 \(l=1\)，此时 \(G=H'\)，没有额外逻辑项。[Sierant，Theorem 14](https://arxiv.org/html/2609.13106v2)

## 高值截断强制稳定子块大小至多二

在每个 \(Q_\lambda\) 上，将 \(\mathcal E_{H'} C\) 的逻辑 Pauli 展开截断，只保留单位项及所有 \(a_v>s\) 的项，记所得全局算子为 \(F_{\rm hi}\)。每个缺项的系数绝对值为 \(|u_{\lambda,v}|\le a_v\le s\)，含归一化 \(1/l\)，故逐块的算子范数误差至多 \((l^2-1)s/l\le Ls=g/8\)。各选用项均由 \(G\) 生成，且 \(Q_\lambda\) 是 \(H'\) 的字符投影。因此 \(F_{\rm hi}\) 在每个 \(G\) 字符块上是标量。若再要求 \(\eta\le g^2/(64D_0)\)，则

    ||C−F_hi||_op ≤ √(D₀η)+Ls ≤ g/4.

以 \(\zeta=(t_1+t_2)/2\) 作断点。原矩阵 \(C\) 恰有两个本征值大于 \(\zeta\)，且两边离断点至少 \(g/2\)。由 Weyl 界，\(F_{\rm hi}\) 也恰有两个，且各值离断点至少 \(g/4\)。因为其每个值的重数为 \(d/|G|\) 的倍数，所以 \(d/|G|\) 必整除 2。\(F_{\rm hi}\) 的高值空间于是是一个秩二稳定子字符块，或同一最大稳定子基中的两条不同射线。

令 \(D=\mathcal E_G C\)。由于 \(H'\subseteq G\)，有 \(\mathcal E_G \mathcal E_{H'}=\mathcal E_G\)。且 \(F_{\rm hi}\) 由该平均保持，所以 \(\|D-F_{\rm hi}\|_{\rm op}\le Ls=g/8\)。两者都按 \(G\) 字符分块，\(F_{\rm hi}\) 在块内标量，因此 \(D\) 在 \(\zeta\) 之上的谱投影等于 \(F_{\rm hi}\) 的同一投影 \(Q\)。上一段说明 \(Q\) 恰是一个秩二稳定子编码。

## 双峰投影误差与纯度比较

令 \(P\) 为 \(C\) 前两维的投影。若 \(x_i\) 是其单位本征向量（\(i=0,1\)），\(u_j\) 是 \(D\) 的低于 \(\zeta\) 的单位本征向量，对应本征值 \(\lambda_j\)，则

    (t_i−λ_j)⟨u_j,x_i⟩=⟨u_j,(C−D)x_i⟩,    t_i−λ_j≥g/2.

逐项平方求和，并用 (2)，给

    Tr[P(I−Q)] ≤ 4||C−D||_HS²/g² ≤ 4D₂η/g².

故编码距离 \(\varepsilon=1-\operatorname{Tr}(PQ)/2\le2D_2\eta/g^2\)。由现有的两个稳定子锚点二阶估计，\((L_{01}-2)_+\le10\varepsilon\le20D_2\eta/g^2\)。[编码二阶稳定性](rank7_rank2_stability_route.md)

取

    η_* = min(η_set, s⁴/L², g²/(64D₀)),
    r_eq(g) = min(√(η_*/84), g/√(3360 D₂)).

由于 \(t_0=t_1=1\)，正向证书有 \(\gamma_{02}=0\)、\(\gamma_{01}=t_6^2(1-t_2)(1-t_3)\le t_6^2\)。Proposition 2、Theorem 7 给

    G_μ(V)−G_μ(I) ≤ 168 t₆² (L₀₁−2)_+−η.

若 \(\eta\ge\eta_*\)，由 \(L_{01}\le5/2\) 与 \(84t_6^2\le\eta_*\) 得非正。若 \(\eta<\eta_*\)，上述二阶稳定性及 \(3360 D_2 t_6^2/g^2\le1\) 得非正。Lemma 1 与填充纯 stabilizer 辅助位给任意尺寸二分割的结论。证明仅在最后使用 \(t_0=t_1\) 消去 \(\gamma_{02}\)。因此这个二维支撑舍入本身也适用于未必等顶、但 \(t_1-t_2\ge g\) 的谱。[正向系数审计](rank7_forward_coefficients_independent.md) · [Sierant，Lemma 1、Proposition 2、Theorem 7](https://arxiv.org/html/2609.13106v2)

同一个全局截断也给有序两条线的另一种舍入证明。若 \(t_0-t_1\ge g\)，则在 \((t_0+t_1)/2\) 处的 \(F_{\rm hi}\) 高值空间恰为一维，强制 \(G\) 最大交换。于是对 \(C\) 的前两条简单谱线分别应用谱投影的交换子估计即可。两种几何只差截取一维或二维的谱簇。
