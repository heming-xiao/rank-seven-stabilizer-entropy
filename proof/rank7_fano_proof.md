# 3|3 二分割的 Schmidt 秩 7：计算基最优性

2026-11-17。推导与有理证书已完成，独立核验与查新以随附记录为准。这里的维数固定为两侧各 8；命题覆盖这一维数下整个 Schmidt 秩 7 谱类和所有局部酉。

## 命题

设 `M = diag(μ₀,…,μ₆,0)`，其中 `μ₀ ≥ ⋯ ≥ μ₆ > 0` 是 Schmidt 振幅。对任意 `U_A,U_B ∈ U(8)`，将 Schmidt 向量对齐到递减排序的计算基，可使纯态的二阶稳定子 Rényi 熵达到全局最小。

## 与已知结果的接口

记 `N = V M V†`。使用 [Sierant, arXiv:2609.13106v2](https://arxiv.org/html/2609.13106v2) 的 Corollary 1、Proposition 2、Theorem 7。Corollary 1 将两侧任意局部酉的优化归约到单一 `V ∈ U(8)` 的稳定子纯度 `Gμ(V)`。Proposition 2 给

    Gμ(V) = I(μ) + 6d² Q_(1^4)(N) + 18d c_F(N²) − D(N),
    D(N) ≥ 0,  D(M) = 0.

Theorem 7 给 `Q_(1^4)(N) ≤ q c_F(N²)`，其中 `q=4/d=1/2`，并且计算基处取等，因为 `M` 只支撑前七个坐标。所以只需证明 `c_F(N²) ≤ c_F(M²)`。此前 Theorem 8 证明此类比较至 Schmidt 秩 6。

## 任意本征基产生一个分数三元系

令 `u₀,…,u₇` 是 `N²` 的一组任意正交归一本征基，最后一个向量对应零值。令 `u_A` 为四个有序本征向量的单位楔积，`p_A = ||Π_F u_A||²`。由 Eq. (47)，若 `t_i=μ_i²`，

    c_F(N²) = Σ_{A⊂{0,…,6}, |A|=4} p_A ∏_{i∈A} t_i.

对全体八个标签，任取三元集合 `S`，有

    Σ_{|A|=4, A⊃S} p_A = q.

理由是 Theorem 17 给单次内乘 `D: C^8 ⊗ W_F → Λ³ C^8` 满足 `DD†=q I`。在右端对单位向量 `u_S` 求期望，在左端用共轭本征基和 `W_F` 的正交基展开，即得到上式。楔积的符号在绝对值平方中消失。对固定 `|S|=k≤3`，把包含它的三元组之上述等式相加，并将同一四元组的重数 `C(4-k,3-k)` 除掉，得到

    Σ_{|A|=4, A⊃S} p_A = q C(8-k,3-k)/C(4-k,3-k).

对 k=0,1,2,3，右端依次是 14q、7q、3q、q。剔除标签 7 后，任取 `S⊂{0,…,6}` 且 `|S|=2`，有 `Σ_{A⊂{0,…,6}, A⊃S}p_A=3q−q=2q`。七个标签内的单点和与总和同理为 `4q`、`7q`。

用三元补集 `B={0,…,6}\A` 编号，令 `x_B=p_A/q`。固定一对标签 `e`。用容斥从总和去掉含任一标签的四元组，得到

    Σ_{B⊃e} x_B = 7 − 4 − 4 + 2 = 1,   x_B ≥ 0.

这就是七个顶点上的分数 Steiner 三元系。计算基参考向量 `x*` 的七个三元组是 `(0,1,6),(0,2,5),(0,3,4),(1,2,4),(1,3,5),(2,3,6),(4,5,6)`。原四元组必须是计算基中的仿射平面，即四标签 XOR 为零，这等价于补三元组 XOR 为 7；每对不同标签有唯一补全的第三个标签。由原文 Eq. (39) 每个平面贡献 `p_A=q`，故 `x*` 实由计算基给出。

## 全体排序权重的精确证书

把目标除以固定正数 `q ∏_{i=0}^6 t_i`，得到

    Σ_B x_B ∏_{i∈B} a_i,    a_i = 1/t_i,    0 < a₀ ≤ ⋯ ≤ a₆.

令 `b₀=a₀`、`b_i=a_i−a_{i−1}`，所以 `a_i=Σ_{h≤i}b_h` 且所有 `b_h≥0`。对一个指标多重集 `m=(h₁≤h₂≤h₃)`，令 `c_{m,B}` 为 `∏_{i∈B}(Σ_{h≤i}b_h)` 中 `∏_{h∈m}b_h` 的系数。

`../rank7_fano_dual.json` 为全部 `C(9,3)=84` 个 `m` 存储了 21 对标签的有理价格 `y_{m,e}`。每个证书满足

    Σ_{e⊂B, |e|=2} y_{m,e} ≥ c_{m,B}   (全部 35 个 B),
    Σ_e y_{m,e} = Σ_B c_{m,B} x*_B.

因此对任一可行 `x`，用 `x_B≥0` 乘第一组不等式，再用每对恰覆盖一次，得到 `Σ_B c_{m,B} x_B ≤ Σ_e y_{m,e} = Σ_B c_{m,B} x*_B`。这里等式约束允许负价格。最后以非负 `∏_{h∈m}b_h` 加权求和，得到全部排序正谱的目标比较。

生成程序 `../rank7_fano_dual.py` 用 LP 找对偶候选，再以 Fraction 对全部 2,940 个不等式和 84 个等式精确验证，因而证明不依赖求解器的浮点容差。证书只需有理加法与整数比较即可重验。

## 推论与适用维数

`c_F(N²) ≤ c_F(M²)` 代回 Proposition 2、Theorem 7，得

    Gμ(V) ≤ I(μ) + (6d²q+18d)c_F(N²)
          ≤ I(μ) + (6d²q+18d)c_F(M²) = Gμ(I).

由 Corollary 1，即得命题。已有定理覆盖秩 ≤6，因此合并后覆盖 3|3 二分割的所有 Schmidt 秩至 7 的谱。此处的分数三元系等式使用恰好一个零方向。更大物理维数下，仍有多个零方向，本证明的等式不能照搬。也未处理满秩 8，此时 Theorem 7 的压缩界已不适用。
