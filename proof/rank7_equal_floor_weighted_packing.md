# 两条最低腿相等时的加权外积亏量

2026-11-18。取谱 \((1,r,r,a,b,c,c)\)，其中 \(1\ge r\ge a\ge b\ge c>0\)。固定任意物理正交本征架，用 \(w_I=\|\Pi_Fx_I\|^2/(4/d)\) 表示归一四楔权。设 \(E\) 是实际与排序代表的归一外积重叠差，\(U=W-W_{\mathrm{CB}}\) 是共享首腿混合极化中的加权四楔差。此处证明两者可由同一组非负容量亏量控制。

## 加权极化亏量的精确分解

对尾指标 \(j,k\in\{3,4,5,6\}\)，记 \(A_j=w_{012j}\)、\(A=\sum_j A_j\)、\(B_{jk}=w_{01jk}+w_{02jk}\)、\(B=\sum_{j<k}B_{jk}\)，以及 \(d_j=\sum_{k\ne j}B_{jk}\)。排序代表的 \(A_3=1\)、\(B_{45}=B_{46}=1\)，其余同类权为零。因此 \(W_{\mathrm{CB}}=2ra+2bc\)。置

\[
 \nu=2A+B-4,\quad x=1-A,\quad u=1-A_3,\quad v=1-A_3-A_4,
\qquad s_3=2u-d_3,\quad s_{34}=2v-(d_3+d_4-2),\quad z=v-B_{34}.
\]

这些亏量均非负。\(x,u,v\) 来自三腿补全。对第 3、4 腿分别在两个固定头配对上用三腿补全，得 \(d_j\le2(1-A_j)\)，故 \(s_3,s_{34}\ge0\)。五标签集 `01234` 的所有内部四楔总权至多一，特别地 \(A_3+A_4+B_{34}\le1\)，故 \(z\ge0\)。[三类物理容量](reviews/rank7_ambient_independent_review.md)

令 \(h=1-r\)、\(q=r-a\)、\(p=a-b\)、\(t=b-c\)，使正向差按指标 `0,2,3,4,6` 依次为 \(h,q,p,t,c\)。为避免混淆，本记中的 \(q\) 只表示间隙，外积归一化因子均写为 \(4/d\)。记 \(g=hq\)。逐项展开 \(W=2r\sum_j t_j A_j+\sum_{j<k}t_jt_k B_{jk}\) 得

\[
U=c^2\nu-D_U,
\qquad
D_U=2c(r-c)x+2(r-c)pu+t(2r-a-c)v+cp,s_3+ct,s_{34}+(p+t)t z\ge0.
\]

例如，从四条等底概率 \(c\) 出发，提高两条最大尾概率时，加在 \(U\) 上的原始线性增量分别是 \((p+t)[2r(A_3-1)+cd_3]\) 与 \(t[2rA_4+c(d_4-2)]\)，二次增量是 \((p+t)t B_{34}\)。以上亏量分解由直接代入得到。[共享首腿极化](rank7_general_two_probe_matching.md)

## 线性外积保留同一组亏量

只含 \(h,q,c\) 的正向四次项，与将 \(p=t=0\) 后的三档谱 \((h+q+c,q+c,q+c,c,c,c,c)\) 完全相同。该三档谱不需要最大概率为一，直接代入六块容量式可得

\[
 E_{h,q,c}\le c^2 H_0\nu-c(h+q)q^2x,
 \qquad H_0=g-c(h+3q)-\tfrac52 c^2.
\]

具体地，若最大值 \(R=h+q+c\)、中间值 \(M=q+c\)，一般六块的 \(\nu\) 价格是 \(c^2[M(R-M)-(2R+M)c+c^2/2]\)，\(x\) 价格是 \(-c(R-c)(M-c)^2\)。其余四个容量亏量依然带非正系数。[六块容量式](rank7_three_level_124_packing_and_scalar.md)

带 \(p\) 或 \(t\) 的全部四次项均是旧正向证书已完成的非正成本。下表保留其中七项的精确亏量。精确亏量指排序系数减实际同一项系数。

| 正向单项式 | 实际系数 | 精确亏量 |
|---|---|---|
| \(hqcp\) | \(2A+2A_3+d_3\) | \(2x+s_3\) |
| \(hqct\) | \(2A+2(A_3+A_4)+d_3+d_4\) | \(2x+s_{34}\) |
| \(hq^2p\) | \(A_3\) | \(u\) |
| \(hqp^2\) | \(2A_3\) | \(2u\) |
| \(hqpt\) | \(4A_3+2A_4+B_{34}\) | \(2u+v+z\) |
| \(hq^2t\) | \(A_3+A_4\) | \(v\) |
| \(hqt^2\) | \(2(A_3+A_4)+B_{34}\) | \(v+z\) |

这些计数由 \(h\) 强制第一腿为 0、\(q\) 强制不同的腿取自 \(\{1,2\}\) 推出。例如 \(hqpt\) 项在含两条中间腿和尾 3 时有四种分配，在尾 4 时有两种分配，只有一条中间腿时必须同时用尾 3、4。\(hqcp\) 项对包含三条头腿的每个四楔先计两次，再当尾 3 出现时多计两次。只含一个中间腿的额外和恰是 \(d_3\)。[正向系数证书](rank7_forward_coefficients_independent.md)

把 \((g/2)D_U\) 也展开，非平底部分只含表中七项，所需亏量分别是 \(x+s_3/2,x+s_{34}/2,u,u,u+(v+z)/2,v,(v+z)/2\)，各自不超过对应的已证精确亏量。其平底部分仅有 \(c hq^2 x\)，而已有 \(c(h+q)q^2x\)。因此全域得到

\[
\boxed{\quad U=c^2\nu-D_U,\qquad E\le c^2 H_0\nu-(g/2)D_U.\quad}
\]

若 \(\nu\le0\)，仍直接使用总的正向证书 \(E\le gc^2\nu\)。故对 \(H_0\le0\) 的整个谱区域，归一外积重叠已有无条件比较。一般的正增益分支满足 \(\nu>0\)、\(H_0>0\)、\(D_U/(c^2\nu)<2\)。由重标度后的三档谱标量引理还得 \(g>16c^2\)。该分支的全谱支付需要混合和压缩的定量比较。[三档标量引理](rank7_three_level_124_packing_and_scalar.md)

## 直接降低增益价格的九条容量证书

同一个物理框架还满足下列更强亏量。每个 \(\Delta_{ijkl}\) 是正向四次系数的排序值减实际值。每条证书都只使用原有 98 行，通过对 35 个四楔列的有理系数比较精确验证。[精确核验器](../verification/verify_rank7_equal_floor_packing.py)

| 系数 | 单项式 | 已证亏量 |
|---|---|---:|
| \(0466\) | \(htc^2\) | \(\nu\) |
| \(2466\) | \(qtc^2\) | \(3\nu\) |
| \(3466\) | \(ptc^2\) | \(4\nu\) |
| \(3666\) | \(pc^3\) | \(4\nu\) |
| \(4466\) | \(t^2c^2\) | \(5\nu/2\) |
| \(4666\) | \(tc^3\) | \(5\nu\) |
| \(2236\) | \(q^2pc\) | \(\nu\) |
| \(0233\) | \(g p^2\) | \(2\nu\) |
| \(0234\) | \(gpt\) | \(2\nu\) |

例如 `0466` 的成本为 \(3T_0-L_{05}-L_{06}\)。两个有向容量给 \(T_0-L_{0j}\le2\)，而 \(T_0\le4-\nu\)，所以成本至多 \(8-\nu\)。其余各条用核验器给出的稀疏对偶价格。对任一表列斜率 \(k\)，核验器逐列比较旧行的非负加权和与原成本加 \(k\) 倍的 \(L_{01}+L_{02}\) 成本，并验证旧容量加权总和在排序代表取等。

前七个项与 \((g/2)D_U\) 无重复，最后两个只用已保留精确亏量的一半支付 \(D_U\)，故另一半尚各有至少 \(\nu\)。只用四项 \(0466,2466,4466,4666\)，总亏量为 \(c^2\nu[t(h+3q)+\tfrac52t^2+5tc]\)，恰使 \(H_0\) 中 \(c\) 变为 \(b=c+t\)。因此独立得到

\[
\boxed{E\le c^2 H_b\nu-(g/2)D_U,\qquad H_b=g-b(h+3q)-\tfrac52b^2.}
\]

这四条正向系数证书在下表单列容量价格，便于只核这一步。记 \(D_{ij}\) 为排除 \(i\) 且包含 \(j\) 的旧有向行，\(P_{ij}\) 为排除两标签的旧点对行。表内每个正权后乘所列行。

| 系数 | 有向行及价格 | 点对行及价格 | 容量总和 |
|---|---|---|---:|
| \(0466\) | \(D_{30}+D_{40}+2D_{50}+2D_{60}\) | 无 | \(12\) |
| \(2466\) | \(D_{12}+D_{21}+D_{30}+D_{40}+2D_{50}+2D_{60}+D_{61}+D_{62}\) | \(P_{05}+2P_{34}+3P_{35}+2P_{36}+3P_{45}+2P_{46}+3P_{56}\) | \(36\) |
| \(4466\) | \((D_{12}+D_{21})/2+D_{30}+D_{40}+(7D_{50}+4D_{51}+4D_{52}+D_{53}+D_{54})/3+(13D_{60}+7D_{61}+7D_{62}+D_{63}+D_{64}+3D_{65})/6\) | \((P_{01}+P_{02})/2+P_{34}\) | \(30\) |
| \(4666\) | \(D_{12}+D_{21}+2D_{30}+2D_{40}+3D_{50}+D_{51}+D_{52}+3D_{60}+D_{61}+D_{62}\) | \(P_{01}+P_{02}+2P_{34}+P_{35}+P_{36}+P_{45}+P_{46}\) | \(40\) |

再保留 \(3466,3666\) 会另减 \(4pb\)。其余三项也可以保留。得到

\[
\boxed{E\le c^2 H_1\nu-(g/2)D_U,\qquad
H_1=g-b(h+3q)-\tfrac52b^2-4pb-\frac{q^2p}{c}-\frac{gp(p+t)}{c^2}.}
\]

特别地，正增益迫使 \(g-b(h+3q)-\tfrac52b^2>0\)，从而按同一三档谱标量引理对辅助谱 \((h+q+b,q+b,q+b,b,b,b,b)\) 重标度，得 \(g>16b^2\)。这比上一节的 \(g>16c^2\) 强。所有亏量都属于同一个四楔占据向量；没有在改变谱参数时改变实际框架。
