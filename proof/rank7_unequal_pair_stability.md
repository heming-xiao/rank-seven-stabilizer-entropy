# 不等秩二谱的 Pauli 稳定性

2026-11-17。设 \(C_0=2|x\rangle\langle x|+|y\rangle\langle y|\)，\(x,y\) 为复正交单位向量，\(d=2^n\ge8\)。记

    δ₀ = 41−F_P(C₀)/d,       F_P(C₀)=Σ_(W Pauli) Tr(C₀ W)^4.

则 \(\delta_0\ge0\)，且存在同一稳定子基内两条不同本征线的投影 \(R_+,R_-\)，使

    ||C₀−(2R_++R_−)||_HS² ≤ 40δ₀.

当 \(\delta_0\le1/4\) 时，右端可取 \(11\delta_0\)。更进一步，若 \(C=C_0+K\)，其中 \(K\succeq0\) 的秩至多五、\(KC_0=0\)、\(\|K\|_{\rm op}\le1/2048\)，则同样存在 \(R_+,R_-\) 使

    ||C₀−(2R_++R_−)||_HS² ≤ 80 Δ_d(C)/d.

这些界不依赖量子比特数。末式直接使用完整谱的实际缺陷，没有额外的尾部误差项。

## 超高值标签生成一个稳定子二能级编码

令 \(c_W=\operatorname{Tr}(C_0W)\)。有 \(\sum_W c_W^2=5d\)、\(|c_W|\le3\)。因为 \(\Lambda^4C_0=0\)，原文缺陷对 \(C_0\) 为 \(\Delta_d(C_0)=d[3(5)^2-2(17)]-F_{\mathrm P}(C_0)=d\delta_0\)。Theorem 14 给 \(\delta_0\ge0\)，以及

    Δ_d(A)/d ≥ (4/d²) Σ_(unordered W,W' anti) Tr(AW)²Tr(AW')².        (1)

等号 \(\delta_0=0\) 时，Theorem 14 的等号条件等价于 \(C_0\) 在稳定子基中对角。编码的两个非零特征值简单，因此此时两条本征线是同一稳定子基的成员。[Sierant，Theorem 14](https://arxiv.org/html/2609.13106v2)

在其余推导中先设 \(\delta_0\le1/4\)。取 \(H_{\rm hi}=\{W:|c_W|>\sqrt7\}\)，并按 Pauli 模相位标签令 \(H=\langle H_{\rm hi}\rangle\)。任意两个反对易 Hermitian Pauli 的期望平方和在态 \(C_0/3\) 上至多一，故 \(H_{\rm hi}\) 两两对易。按高值和低值分开估计四次矩得

    (41−δ₀)d ≤ 7·5d + 2 Σ_(W∈H_hi)c_W²,
    |H_hi| ≥ (6−δ₀)d/18 > d/4.

因此交换群 \(H\) 的大小是 \(d/2\) 或 \(d\)。若为 \(d\)，任何群外 Pauli 都与某个超高值生成元反对易，故 \(c_W^2\le2\)。在该最大群的共同本征基中令 \(p_i=\langle i,C_0 i\rangle\in[0,2]\)，\(\sum p_i=3\)。在群上使用字符 Parseval，并对群外用 \(c_W^2\le2\)，得到 \( \sum_i p_i^2 \ge (31-\delta_0)/7\ge30/7\)。又记前两大元为 \(p_{(1)},p_{(2)}\)，则

    Σ_i p_i² ≤ p_(1)²+(3−p_(1))p_(2) ≤ 4+p_(2).

最后一步因固定 \(p_{(2)}\) 时该函数在 \(p_{(1)}\in[p_{(2)},2]\) 上递增。因此 \(p_{(2)}\ge2/7\)。对每个超高值标签，少数符号概率质量（以迹为 3 的未归一化权重计算）小于 \((3-\sqrt7)/2<2/7\)。故最大的两条不同字符线在所有超高值生成元上取相同符号，进而在 \(H\) 上相同，矛盾。于是 \(|H|=d/2=:m\)，其各个联合本征空间维数都是二。

## 退相干损失与共同编码

令 \(\mathcal E_H\) 为 \(H\) 共轭平均。对每个不在中心化子 \(H^\perp\) 的 Pauli，恰有 \(d/4\) 个 \(H\) 标签与之反对易。因此它至少与 \(|H_{\rm hi}|-d/4\ge(3-2\delta_0)d/36\) 个超高值标签反对易。两种标签集合互不相交，故式 (1) 无重复计数地给

    δ₀ ≥ (7/9)(3−2δ₀) ||C₀−E_H C₀||_HS².

当 \(\delta_0\le1/4\) 时，退相干损失至多 \(e=18\delta_0/35\)。等价的损失式为 \(\|A-\mathcal E_H A\|_{\rm HS}^2=\tfrac12\mathbb E_{W\in H}\|[A,W]\|_{\rm HS}^2\)。在 \(C_0\) 的本征基中，各非零本征线与其补空间的谱间隔至少为 1。所以对 \(v=x,y\)，投影 \(P_v\) 的各交换子范数不超过 \(C_0\) 的对应交换子范数，退相干损失至多 \(e\)。

对秩一 \(P_v\)，该损失等于 \(1-\sum_\lambda\|Q_\lambda v\|^4\)，其中 \(Q_\lambda\) 为 \(H\) 的秩二字符投影。故 \(v\) 在某一字符块上至少有 \(1-e\) 的质量。若 \(x,y\) 的主要字符块不同，则必有一个超高值生成元区分它们。这个生成元在 \(C_0\) 的期望绝对值至多 \(1+6e<\sqrt7\)，因为理想的相反符号给 \(2-1=1\)，每条线的符号偏差至多 \(2e\)。矛盾。故有同一个 \(Q\) 满足

    ε_x=1−||Qx||²≤e,        ε_y=1−||Qy||²≤e.

## 逻辑 Pauli 倒谱给两条不同稳定子线

取 \(H^\perp/H\) 的三个非零元的 Hermitian 代表 \(L_i\)，\(i=1,2,3\)。它们在 \(Q\) 上为三个逻辑 Pauli 轴。对任意 Hermitian \(A\)，令 \(u_i=\operatorname{Tr}(Q A Q L_i)\)。选择 \(H\) 的实际交换表示后，\(L_i H\) 中的迹是各字符块的 \(\operatorname{Tr}(Q_\lambda A Q_\lambda L_i)\) 的 Walsh 变换。故

    m^(−1) Σ_(W∈L_i H) Tr(AW)²
      = Σ_λ Tr(Q_λ A Q_λ L_i)² ≥ u_i².

不同非零逻辑轴的两组 coset 之间任意标签反对易。代入式 (1) 并用 \(4m^2/d^2=1\)，得到

    Δ_d(A)/d ≥ Σ_(i<j) u_i² u_j².                                  (2)

这一步保留全部字符块的平方和，无需逐个 Pauli 减去码外迹误差。

对 \(A=C_0\)，记 \(u=(u_1,u_2,u_3)\)、\(u_{\max}=\max_i|u_i|\)，取对应带正期望符号的逻辑轴 \(\tau\)。\(|u|\) 等于 \(QC_0Q\) 的本征值差。其大本征值至少 \(2(1-\varepsilon_x)\)，小本征值至多 1，故 \(|u|\ge1-2e\ge26/35\)。式 (2) 给

    |u|−u_max = (Σ_minor u_i²)/(|u|+u_max)
              ≤ 2δ₀/|u|³.

因为 \(u_{\max}\ge|u|/\sqrt3\)，且 \(1+1/\sqrt3>3/2\)。令 \(R_\pm=(Q\pm \tau)/2\)，在此把 \(\tau\) 延拓为 \(Q\) 外为零。此二投影来自扩张 \(H\) 的一个最大交换 Pauli 群，因而是同一稳定子基的不同线。令 \(C_*=2R_++R_-\)，设 \(t=\operatorname{Tr}[(I-Q)C_0]\le3e\)。精确算得

    ||C₀−C_*||_HS² = 1+3t−u_max
                    ≤ 11e + 2δ₀/(26/35)³ < 11δ₀    (δ₀>0).

若 \(\delta_0=0\)，前述等号给零距离。若 \(\delta_0>1/4\)，取任意两条不同稳定子线即可用 \(\|C_0-C_*\|_{\rm HS}^2\le10<40\delta_0\)。此外，两个有序本征线的失配和不超过该 HS 平方距离。把两算子在各自完整本征基展开，距离等于 \(\sum_{ij}(\lambda_i-\lambda_j)^2|\langle v_i,w_j\rangle|^2\)，每个非零本征值与其他值的间隔至少为 1。

## 直接以完整谱的缺陷控制编码舍入

现在 \(C=C_0+K\)，\(K\succeq0\)、\(\operatorname{rank}K\le5\)、\(KC_0=0\)，令 \(r=\|K\|_{\rm op}\le1/16\)，\(\eta=\Delta_d(C)/d\)。若 \(\delta_0\le1/4\)，仍用 \(C_0\) 定义同一个超高值群 \(H\)。每个超高值标签在 \(C\) 上的迹绝对值至少 \(\sqrt7-5r>9/4\)，且与任一非中心化标签反对易的超高值标签至少 \(5d/72\) 个。式 (1) 给

    η ≥ (45/32)||C−E_H C||_HS².

在 \(C\) 的本征基中，\(x,y\) 的独立本征间隔均至少 \(1-r\ge15/16\)。故其各自的投影退相干损失至多 \((32/45)(16/15)^2\eta\le\eta\)。若 \(\eta\le1/8\)，用 \(C_0\) 的超高值标签排除不同主要字符块的同一论证可用，得到共同 \(Q\) 及 \(\varepsilon_x,\varepsilon_y\le\eta\)。同时

    Tr(QK) ≤ r Tr[Q(I−P_x−P_y)] = r(ε_x+ε_y) ≤ 2rη.

对 \(A=C\) 应用式 (2)。\(QCQ\) 的本征值差至少 \(1-2\eta\ge3/4\)，因为其大本征值至少 \(2(1-\varepsilon_x)\)，而在 \(Q\) 中取一个与 \(Qx\) 正交的单位向量，其完整 \(C\) 期望至多 1。取 \(QCQ\) 最大模的逻辑轴，再用 \(\operatorname{Tr}(QK)\) 控制该轴在 \(QC_0Q\) 上的差。于是对应的 \(C_*\) 给

    ||C₀−C_*||_HS² ≤ 9η+2η+2η/(3/4)^3+2rη ≤ 16η.

若 \(\eta\ge1/8\)，任意两条不同稳定子线已给距离平方至多 \(10\le80\eta\)。

最后若 \(\delta_0>1/4\) 且 \(r\le1/2048\)，可以直接推出 \(\eta\ge1/8\)。按 \(d^{-1}\sum_W\) 归一化求和，令 \(p_W=\operatorname{Tr}(C_0W)\)、\(k_W=\operatorname{Tr}(KW)\)。有 \(|p_W|\le3\)、\(|k_W|\le5r\)、\(\sum_W k_W^2/d\le5r^2\)、\(\sum_W p_W^4/d\le41\)。将 \((p+k)^4\) 展开，使用 \(\sum_W p_W^6/d\le9\cdot41\) 和 Cauchy–Schwarz，得到

    [F_P(C)−F_P(C₀)]/d ≤ 172r+270r²+300r³+125r⁴ < 1/8.

此外 \(\|K\|_{\rm HS}^4\ge\operatorname{Tr}K^4\)，所以 \(3(\operatorname{Tr}C^2)^2-2\operatorname{Tr}C^4\ge41\)，且 \(c_{\rm F}(C)\ge0\)。因此 \(\eta\ge\delta_0-1/8>1/8\)。这补全 \(r\le1/2048\) 的完整缺陷舍入。此结论提供不等主要双峰的维数无关稳定性。尚需另外估计它在一般秩七重叠系数中的支付项。[Sierant，Eqs. (101)、(104)、(175)](https://arxiv.org/html/2609.13106v2)
