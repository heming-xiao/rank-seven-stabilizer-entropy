# 秩六孤立最高双峰邻域的独立核验

2026-11-17。独立核验通过。对归一到 \(t_0=1\) 的任意排序正秩七谱，若

    min(t₁−t₂,t₅−t₆) ≥ g > 0

且 \(t_6\) 小于下文的维数无关阈值，则排序计算基在任意尺寸二分割的局部酉轨道上全局最优。特别地，任一秩六谱若最高本征值恰为二重，便有整个相对秩七邻域，无须限制其余四个正值的重数。它同时覆盖边界重数 \((2,2,2)\) 和 \((2,4)\)，也允许附近的最高双峰任意分裂。

同一证明的关键是整体舍入前六维，而非依次舍入六根有序本征线。两个逻辑维数分支如下。[交换高值提取](rank7_moment_free_boundary_neighborhood_review.md) · [全局逻辑截断](../rank7_isolated_doublet_boundary.md)

## 缺陷产生一维或二维的逻辑字符块

设 \(C=N^2\)、\(\eta=\Delta_d(C)/d\)。沿用高值提取和稀少字符核的固定常数 \(\eta_{\rm set},D_0,L\)，取 \(s=g/(8L)\)，并定义

    η_* = min(η_set, s⁴/L², g²/(64D₀)),     𝒜=D₀+L/(4s²).

当 \(\eta\le\eta_*\)，全局逻辑截断 \(F_{\rm hi}\) 在所得交换群 \(G\) 的各字符块内为标量。又 \(\|C-F_{\rm hi}\|_{\rm op}\le g/4\)，\(D=\mathcal E_G C\) 与 \(F_{\rm hi}\) 同块，且 \(\|D-F_{\rm hi}\|_{\rm op}\le g/8\)、\(\|C-D\|_{\mathrm{HS}}^2\le\mathcal A\eta\)。

在 \(t_5,t_6\) 的中点上方，Weyl 界使 \(F_{\rm hi}\) 恰有六个本征值。字符块维数为二的幂，且整除六，因此只能是 1 或 2。\(D\) 的相同阈值谱投影等于 \(F_{\rm hi}\) 的，因为后者在每块为标量并且离阈值至少 \(g/4\)。同样，在 \(t_1,t_2\) 的中点处可取得前二维的一致谱投影。

令 \(P_j,Q_j\) 分别为 \(C,D\) 的前 \(j\) 维投影，\(j=2,6\)。逐项比较两个矩阵的高、低本征向量，有 \((t_i-\lambda_k)\langle u_k,x_i\rangle=\langle u_k,(C-D)x_i\rangle\)，其中 \(t_i-\lambda_k\ge g/2\)。平方求和给

    Tr[P_j(I−Q_j)] ≤ 4𝒜η/g²,    ||P_j−Q_j||_HS² ≤ 8𝒜η/g². (1)

这里用的是在相应阈值两边的谱隙，无需同一侧的任何更细间隔。

## 二维字符块：整体六维对齐的一阶交叉项为零

若每个字符块二维，可用 Clifford 把它们送为沿某一非零二元标签 \(a\) 的两点坐标陪集。\(Q_6\) 包含三个这种陪集。三个不同的商空间标签张成一个仿射二维空间，所以这三个陪集位于一个八点仿射三空间 \(H\) 中。记 \(D_{\rm miss}\) 为 \(H\) 内未占据的第四个陪集。此处 \(H\) 指坐标仿射空间；\(\operatorname{dir}H\) 指其线性方向。

取 \(P_6,Q_6\) 的主角直接旋转。它可写成 \(U=e^K\)，其中 \(K\) 反 Hermitian，且相对 \(Q_6\oplus Q_6^\perp\) 完全非对角。具体地，每个非零主角 \(\theta_j\) 在一对 \(Q_6,Q_6^\perp\) 的主向量上用二维旋转实现，其余方向固定。故 \(UQ_6U^\dagger=P_6\)，且 \(h=\|K\|_{\rm op}=\max\theta_j\) 满足

    h² ≤ (π²/4) Σ_j sin²θ_j
       = (π²/8)||P₆−Q₆||_HS² ≤ π²𝒜η/g² < 10𝒜η/g²

（\(\eta=0\) 时余项直接为零）。将实际七根向量以 \(U^\dagger\) 拉回为参考。其前六根全部在 \(Q_6\)，尾根在 \(Q_6^\perp\)。因此参考 \(L_{01},L_{02}\le2\)，用的是固定二平面支撑在八点仿射空间里的定理，允许七根参考线在三个已占陪集间任意混合。[八点仿射支撑界](../rank7_two_link_astra.md)

下面复核同步沿 \(e^{tK}\) 变化时，两个 \(L\) 的每个四楔平方范数的一阶导数都为零。按 \(\Pi_{\mathrm F}\) 的平行仿射平面方向分解交叉内积，它只可能匹配同一个方向的分量。

- **全取前六根的参考项。** 非零坐标仿射面在 \(H\) 内，并只占三个可用的 \(a\) 陪集。若其方向不含 \(a\)，商空间上应有四个不同标签，这不可能。因此参考项只含 \(\operatorname{dir}H\) 内含 \(a\) 的方向。一次微分将一根头部向量送到 \(Q_6^\perp\)。若该坐标在 \(H\) 内，它只能在 \(D_{\rm miss}\)，恰出现一次。任何含 \(a\) 的平面在每个陪集有零或两个点，故与参考方向不相交。若该坐标在 \(H\) 外，它是唯一外部标签，四点 XOR 不可能为零。
- **取尾根的参考项。** 非零坐标项需要尾根从 \(H\) 内取值，具体只能在 \(D_{\rm miss}\)。因此所有四个商标签必须不同，方向位于 \(\operatorname{dir}H\) 且不含 \(a\)。改变一根头部向量后，若变化坐标和尾坐标都在 \(H\) 内，则两者都在 \(D_{\rm miss}\)，任何可能的平面方向就包含 \(a\)，与参考方向不相交。若恰一坐标在 \(H\) 外，XOR 不为零。若两坐标都在 \(H\) 外，任何可能的平面都因同时含 \(H\) 内外的点，方向不可能包含于 \(\operatorname{dir}H\)。最后，改变尾根使其落入 \(Q_6\)，于是四根都在 \(Q_6\)，又只有含 \(a\) 的方向。

因此每个参考投影四楔与它的导数都正交。该证明不要求把头部六根分配为三个可分辨的谱双峰，只要求整个支撑的布置。由通用的 \(640h^2\) 二阶界及零一阶导，得到

    (L₀i−2)_+ ≤ 320h² ≤ 3200𝒜η/g²,       i=1,2.

因为 \(\gamma_{01}\le2t_6\)、\(\gamma_{02}\le t_6\)，该分支的加权超额至多 \(9600\,t_6\mathcal A\eta/g^2\)。[四楔 Taylor 常数](rank7_single_anchor_compensation_independent_review.md)

## 最大交换群：两个小谱差分别抵消

若 \(G\) 最大交换，则 \(Q_2\) 是同一稳定子基中两个格点的张成空间。式 (1) 给编码误差 \(\varepsilon=1-\operatorname{Tr}(P_2Q_2)/2\le2\mathcal A\eta/g^2\)。用编码的二阶估计可得 \((L_{01}-2)_+\le20\mathcal A\eta/g^2\)。

若 \(b_0b_2=0\)，\(\gamma_{02}=0\)。否则 \(x_0,x_2\) 都是简单谱线，其谱隙分别至少 \(b_0\) 和 \(\min(g,b_2)\ge g b_2\)。比较 Pauli 交换子并平均，得到它们在共同稳定子基的各自最佳格点失配至多 \(\delta_0=\mathcal A\eta/b_0^2\) 和 \(\delta_2=\mathcal A\eta/(g^2b_2^2)\)。若最佳格点重合，则因为两根实际线正交，至少其中一个重叠概率至多 \(1/2\)。相应的 \(\delta_i\ge1/2\)，改以任一不同参考格点的失配仍至多 \(2\delta_i\)。所以总可选两个不同参考格点，失配各至多 \(2\delta_i\)。用几何平均的两锚点界，得到

    γ₀₂(L₀₂−2) ≤ b₀ b₂ t₆ · 29√(2δ₀·2δ₂)
                 = 58𝒜η t₆/g.

与 \(\gamma_{01}(L_{01}-2)\) 合并，利用 \(g\le1\)，本分支加权超额至多 \(98\,t_6\mathcal A\eta/g^2\)。[不对称两锚点界](../rank7_second_doublet_boundary.md)

## 邻域与单酉上界

例如可取

    t₆ ≤ min(η_*/336, g²/[168·9600·𝒜]).

近情形 \(\eta\le\eta_*\) 的任一逻辑分支都使加权超额乘 168 后被 \(\eta\) 支付。远情形利用 \(L_{ij}\le5/2\) 及 \(\gamma_{02}\le\gamma_{01}\le2t_6\)。由正向证书、Proposition 2、Theorem 7 得到单酉比较，Lemma 1 与附加纯稳定子位给全切割的结论。

对最高值二重的任一固定秩六边界谱，\(t_1-t_2\) 和 \(t_5-t_6\) 在边界都严格为正，故在充分小的相对秩七邻域可取统一 \(g>0\)。此处没有其它边界谱重数要求。[正向证书](../rank7_forward_coefficients_independent.md) · [Sierant，Lemma 1、Proposition 2 和 Theorem 7](https://arxiv.org/html/2609.13106v2)
